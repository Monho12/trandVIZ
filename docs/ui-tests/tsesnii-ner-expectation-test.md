1. "Энэ сайт англи Wikipedia-ийн уншилтаас огцом өссөн сэдвийг олж, цаашид яах вэ гэдгийг таамагладаг. Сүүлийн цэс дээр дарвал **юу гарч ирнэ гэж бодож байна вэ?**"
   (Эхний өгүүлбэрийг зөвхөн эхний screenshot-ын өмнө нэг удаа хэлнэ.)

## Ангилал (хариулт бүрийг тэмдэглэхдээ)

- **Т (таарсан)**: өнгөрсөн таамаг, хэр зөв / буруу байсан, нарийвчлал, итгэж болох эсэхийг дурдсан.
- **Х (хэсэгчлэн)**: таамаг эсвэл model-ийн тухай гэж ойлгосон ч "өнгөрсөн" ба "зөв эсэх" аль нэг нь дутуу.
- **Б (буруу)**: өөр зүйл (жишээ нь "баримт бичиг", "эх сурвалж", "тохиргоо", "найдвар" гэсэн утгаар).

## Шийдвэрийн дүрэм (тестээс **өмнө** тогтоосон)

1. 1-р асуултын **Т**-ийн тоо хамгийн олон нэр ялна.
2. Тэнцвэл **Б** цөөнтэй нь.
3. Тэнцсэн хэвээр бол 100% zoom-д зай ихтэй (богино) нь.
4. 3-р асуултын хариулт зөвхөн нэмэлт мэдээлэл. Дүрмийг дарахгүй, харин тэмдэглэлд бичнэ.
