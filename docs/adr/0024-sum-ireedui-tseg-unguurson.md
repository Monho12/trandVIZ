# Тэмдэг: сум = ирээдүй (таамаг), ● = өнгөрсөн (Anomaly)

(UI/UX grill, Майк сонгосон, Claude санал болгосон, 2026-11-17.) ADR 0014-ийн "▲ нь өнгөрсөн, ↗/🔥 нь таамаг" дүрмийн **▲ тэмдгийг** орлоно.
Тоо нь ADR 0017-ийнхоор хэвээр (×N = анхаарал ÷ t−59…t−7 цонхны медиан).

## Яагаад

▲ (Anomaly) ба ↗ (Rising) хоёулаа "дээш" хэлбэртэй тул нэг visual channel дээр байна (UI дүрэм 1-ийг зөрчинө).
Нүүрний хамгийн түгээмэл карт бол "огцом өссөн, гэхдээ унтрах" (~70%, ADR 0021). Энэ карт `▲ ×3  ↘ унтрах` болж,
дээш ба доош сум зэрэгцэн гарна.

## Шийдвэр

- **Сум (↗ ≈ ↘ г.м.) зөвхөн таамагт.** Anomaly нь сумгүй **●**.
- Сэдвийн график дээр огцом өссөн өдрийн баганад ижил ● тавина: жагсаалт ба график нэг тэмдгээр холбогдоно.
- ● нь "live / шууд" гэж уншигдах эрсдэлтэй. Tooltip ба тайлбарт огноог үргэлж бичнэ (ADR 0018, "одоо" гэж бичихгүй).
- **●-ийн өнгө нь өгөгдлийн төвийг сахисан палитраас** (ADR 0023). Брэндийн улаан биш, учир нь улаан цэг "мэдэгдэл / аюул" гэж уншигдана.
- **Prototype-д хоёр хувилбар:** `● ×3` ба `● огцом ×3`. "×3" ганцаараа шинэ хэрэглэгчид ойлгомжгүй байж болзошгүй.
  Нүүрний картанд үгтэй хувилбар, нягт жагсаалтад богино хувилбар байж болно. Эцсийг нь Майк prototype-оос сонгоно.
