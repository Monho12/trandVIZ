# UI-г шинэчилж болно, гэхдээ Майк prototype-оос сонгосны дараа л. Брэнд ба өгөгдлийн өнгө тусдаа

(UI/UX grill, Майк шийдсэн, 2026-11-17.) `docs/PLAN.md`-ийн "Вэбийн дизайны шийдвэрүүд"-ийн "**Дизайныг өөрчлөхгүй**"
(Майк 2026-11-09) дүрмийг энэ ADR орлоно. Учир нь Trend Intelligence-ийн UI дүрмүүд (төвийг сахисан палитр, итгэлийг хэлбэрээр харуулах,
interval band; PLAN "UI/UX grill-ийн оролт") болон шинэ theme-ийн хүсэл тэр дүрэмтэй шууд зөрчилдөж байсан.

1. **Хамгаалалтын зарчим хэвээр:** "Дизайн дээр зөвхөн Майкийн тодорхой баталсан зүйлийг өөрчилнө." Шинэ дизайныг `/prototype`-оор
   2–3 хувилбар болгож гаргана. Майк нэгийг нь сонгосны дараа л кодод орно. (11-09-нд v2 Майкийн зөвшөөрөлгүй дизайныг өөрчилсөн тул буцаагдсан. Энэ сургамж хэвээр.)
2. **Брэнд ба өгөгдлийн өнгө тусдаа:**
   - Улаан / цэнхэр / цагаан (`#e63946`, `#2a78d6`) нь "Шуугиан"-ы **брэндийн өнгө**: лого, гарчиг, accent.
   - График дээрх **өгөгдлийн өнгө** (таамаг, итгэлийн интервал, өсөлт/бууралт) брэндийн өнгөнөөс тусдаа, төвийг сахисан палитр байна.
     Улаан нь "таамаг" гэсэн утгаа алдана (одоо `--forecast` = `--red` = #e63946).
3. **Бараан theme урьдаас шийдэгдээгүй.** Prototype-ийн 2–3 хувилбарын нэг л байж болно. Майк нүдээрээ хараад шийднэ. WCAG AA заавал.
4. **Хуудасны бүтэц ба цэсийг урьдаас түгжихгүй.** UI grill-ийн "мэдээллийн шатлал" асуултаар шийднэ.

Үр дагавар: `app/static/styles.css`-ийн `:root` дотор брэнд ба өгөгдлийн token-ыг тусад нь нэрлэнэ (prototype сонгогдсоны дараа).

> **2026-11-17 (UI grill-ийн төгсгөл):** prototype нь хоёр шаттай: 1) бүтэц (2 бүтэн хувилбар + variant panel, theme 1), 2) сонгосон бүтэц дээр 3 theme (ADR 0028). Процесс `docs/PLAN.md`-д.
