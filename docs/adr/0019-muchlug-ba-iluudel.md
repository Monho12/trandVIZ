# Нүүрний жагсаалт "ердийнхөөсөө давж өснө" гэсэн асуултад хариулна: долоо хоногийн мөчлөгийг илүүдлээр хасна

(grill-ээр Майк баталсан, 2026-11-17.) ADR 0004-ийн "Top-10 үргэлж 10" хэсгийг орлоно. Тоо бүгд (в)-гүй valid, хэмжигдэх сэдэв дээр.

## Бүтээгдэхүүний шийдвэр

Нүүрний жагсаалтын асуулт **"уншилт өснө" биш, "ердийнхөөсөө давж өснө"** болсон. Model долоо хоногийн мөчлөгийг маш
найдвартай таамагладаг (Ням гарагийн asof-той Rising-ийн ихэнх нь "Лхагва гарагт буцаж өснө"). Гэхдээ энэ нь шинэ мэдээлэл биш.
Иймээс мөчлөгийг хассан. Энэ нь **санаатай солилцоо**: жагсаалтын precision (бодит ≥ +25%) **43.6% → 31.1%** буурсан,
харин бодит илүүдлийн нарийвчлал **45.1% → 58.9%** өссөн (үндсэн хувь 29%, нарийн нь **29.3%**: бүх хэмжигдэх мөр,
`docs/numbers/frequency.md` #9, 2026-11-25).

## Дүрэм

- **Мөчлөг** (h3) = сүүлийн 4 долоо хоногийн ижил гарагийн шилжилтийн (asof гараг → asof+3 гараг) анхаарлын харьцааны медиан − 1.
- **Илүүдэл** e = (1 + таамагласан pct) / (1 + мөчлөг) − 1. **Бодит илүүдэл** = (1 + бодит pct) / (1 + мөчлөг) − 1.
- **Мөчлөгийн өсөлт** ⇔ Rising, мөчлөг ≥ +10% **ба e < +10%** (нэг талын). **Мөчлөгийн бууралт** ⇔ Declining, мөчлөг ≤ −10% **ба e > −10%**.
  Нэг талын байх шалтгаан: мөчлөгөөсөө *бага* өсөх сэдэв (мөчлөг +30%, таамаг +15%) жирийн Rising болж жагсаалтад орох ёсгүй.
  Хоёр талын (|e| < 10%) дүрмээр бол ийм мөр өдөрт 3.1 гардаг, бодит илүүдэл нь ердөө 17% (үндсэн хувиас доор).
- **Нүүрний жагсаалт** = Мөчлөгийн өсөлт биш Rising, таамагласан pct (h3)-ээр эрэмбэлсэн, **дээд тал нь 10, цөөн бол цөөн**. Stable-аар нөхөхгүй.
  Мөчлөгийн өсөлтүүдийг доор нь тусдаа, хураасан "Долоо хоногийн хэвийн өсөлт" хэсэгт харуулна. Нүүр хэзээ ч бүрэн хоосон харагдахгүй.
  Valid дээр 271 өдрийн 102-т жагсаалт 10-аас цөөн, 2-т нь 0 (ихэвчлэн Ба/Мя/Да-ийн asof).
- **Хэмжүүр**: жагсаалтын **бодит илүүдлийн нарийвчлал** (бодит илүүдэл ≥ +10% болсон хувь) нь үндсэн хувьтай харьцуулагдана. Хадгалсан/сэргээж тооцсон
  таамгаас тайлагнана (ADR 0015, 0016). Хамгаалалтын precision@10 (test, 31%) нь хуучин тодорхойлолтын түүхэн тоо хэвээр, дарж бичихгүй.

| (valid) | Хуучин top-10 | Шинэ (нэг талын) | Хоёр талын (татгалзсан) |
|---|---|---|---|
| precision (бодит ≥ +25%) | 43.6% | 31.1% | 37.7% |
| Бодит илүүдэл ≥ +10% | 45.1% | **58.9%** | 51.2% |
| 10-аас цөөн өдөр | 0 | 102 | 81 |

Мөчлөгийн Rising-ийг илүүдлээр задалбал (өдөрт): e < 0 нь 8.3 (бодит илүүдэл 21%), 0…+10% нь 3.5 (32%), **+10…+25% нь 0.65 (61%, бодит ≥ +10% 89%)**.
Мөчлөгөөс эрс давсан цөөн таамаг хамгийн чанартай тул хатуу хоёр ангиллаар хасахгүй. Declining-ийн 39% нь мөчлөгтэй.

## Үр дагавар

- ADR 0004: 🔥, хэмжигдэх сэдвийн шүүлтүүр хэвээр. "Үргэлж 10" нь энэ ADR-ээр орлогдсон.
- Мөчлөгийг тооцоход asof-оос өмнө ≥ 28 хоногийн түүх хэрэгтэй (Snapshot-ийн 366 өдөрт багтана).

## Хэрэгжүүлэлт (#49, 2026-11-25)

`src/cycle.py` (үнэлгээ ба вэб хоёулаа). Тодорхойлолтоос гадна сонгосон зүйлс (Майк хянана):

- **Rising / Declining** = таамагласан pct (h3) ≥ +10% / ≤ −10% (ADR 0004-ийн сумны ±10% хил: ↗ ба 🔥 / ↘ ба ↓).
- **Мөчлөг тодорхойгүй** (NaN): 4 шилжилтийн аль нэг нь байхгүй (asof-оос өмнө < 28 хоног) эсвэл эхлэх өдөр 0 анхаарал.
  Тодорхойгүй мөчлөгтэй сэдэв мөчлөгийн өсөлт/бууралт биш (жирийн Rising бол жагсаалтад орно).
- **Хэмжүүр** = жагсаалтын бүх өдрийн мөрийг нийлүүлсэн хувь (өдрүүдийн дундаж биш): 0-тэй өдөр тоонд нөлөөлөхгүй.
- Давтсан тоо (`tests/test_cycle.py`, data/processed-оос санах ойд, `calibrate.valid_frame`-ийн мөр): (в)-гүй valid, хэмжигдэх, 271 өдөр:
  бодит илүүдэл ≥ +10% **58.9%**, precision (бодит ≥ +25%) **31.1%**, 10-аас цөөн өдөр **102**, 0-тэй өдөр **2**,
  үндсэн хувь (бүх хэмжигдэх мөр) **29.3%**, хуучин top-10-ийн precision **43.6%** (`scoring.top10`, хэвээр). Rising өдөрт 25.9,
  үүнээс мөчлөгийн өсөлт 11.8. "Declining-ийн 39%" нь мөчлөг ≤ −10% байгаа Declining (39.3%); мөчлөгийн бууралт (e > −10%) нь 30.0%.
- API (`/api/*`-ийн сэдэв бүр): `cycle`, `excess` (pct шиг 5%-ийн алхмаар тэг рүү тайрсан тул ±10%-ийн хил хадгалагдана),
  `cyclical` (мөчлөгийн өсөлт эсвэл бууралт). `/api/trending`: `rank` = Давж өсөх жагсаалтын байр (1…≤10), `beyond` (дарааллаар),
  `cyclical_rise` (хэмжигдэх мөчлөгийн өсөлт бүгд, pct-ээр, хязгааргүй), `fires` = жагсаалтын 🔥. `top_n` = 10 нь дээд хил.
- **🔥 (`fire`) өөрчлөгдөөгүй:** мөчлөгийн өсөлт pct ≥ T бол 🔥 хэвээр (жагсаалтад орохгүй). "Тод = pct ≥ T ба мөчлөгийн өсөлт биш" нь ADR 0026, W7.
- Нүүр: picker нь `beyond`-ийг харуулна (цөөн бол цөөн). 0 бол "{хугацаа}: долоо хоног бүр давтагддаг өсөлтөөс илүү өсөх таамаг алга."
  гэсэн нэг мөр, picker ба focus-гүй. Тайлбарт "Долоо хоног бүр давтагддаг өсөлтийг оруулаагүй." нэмэгдсэн. Screenshot: `docs/ui-tests/w3c/`
  (golden өгөгдлийн asof 2026-11-10-нд жагсаалт 1 сэдэвтэй, мөчлөгийн өсөлт 0; хоосон төлөвийг API-г хуурамчаар хоосолж авсан).
