# "Өмнөх таамаг зөв байсан уу?"-г сэргээж тооцсон backtest-ээр харуулна: as-of replay, model хувилбартай

(grill-ээр Майк зөвшөөрсөн (Claude санал болгосон), 2026-11-17.) Сервер таамгийг хаана ч хадгалдаггүй, Render-ийн диск
түр зуурынх (ADR 0011). Тиймээс өнгөрсөн өдрийн таамгийг өгөгдлөөс **дахин тооцно**. Model детерминист, feature causal тул
боломжтой. Ингэвэл хадгалах газаргүйгээр 2026-04-01-ээс эхлэх out-of-sample түүх шууд бий болно. Хадгалсан таамгийн log-ыг
(жинхэнэ "тэр өдөр харуулсан тоо") зэрэгцүүлэн эхлүүлнэ. Гэхдээ энэ хоёрыг нэг тоо болгож холихгүй.

## Дүрэм

1. **Хил: asof ≥ 2026-04-01** (test-ийн эхний өдөр). Шалгасан нь: `src/train.py`, `src/calibrate.py` test-ийг уншдаггүй
   (сургалт train ≥ 2023-07-01, early stopping/сонголт/T/интервал (в)-гүй valid). Test-ийг нэг удаа үнэлсэн commit (6361afe, 2026-11-10)-ээс
   хойш model, feature, цэвэрлэгээ, `feature_list.json` өөрчлөгдөөгүй (зөвхөн серверийн ачаалал, b9fabb3). Model-ийг дахин
   сургавал хил нь тэр хувилбарын сургалт/сонголт/калибровкт ашигласан сүүлийн өдрийн **дараагийн** өдөр болно.
2. **Model хувилбар = model файлууд + `meta.json`-ийн hash.** `trained_at` хангалтгүй: `src/calibrate.py` нь T ба интервалыг
   `trained_at`-ыг өөрчлөхгүйгээр дахин бичдэг. UI: "сэргээж тооцсон, model vXXXXXXX". Өөр хувилбарын үр дүнг нэгтгэхгүй.
3. **As-of replay.** D өдрийн таамгийг түүхий өгөгдлийг ≤ D хүртэл тайраад `clean_frame(end=D)` → feature → model-оор тооцно
   (сервер asof өдөр яг ингэдэг). Бэлэн `clean.parquet`-аас тооцохгүй, учир нь `cap_isolated_spikes` нь t+1 өдрийн утга болон
   төвлөрсөн 29 хоногийн медиан (t+14 хүртэл) ашигладаг: энэ нь look-ahead. Wikimedia D өдрийг D+1-нд гаргадаг тул "≤ D" нь
   D+1-нд бодитоор бэлэн байсан өгөгдөлтэй тэнцэнэ.

## Үлдэх хазайлт (UI ба тайланд шударгаар хэлнэ)

- **Сэдвийн жагсаалт нь эргээд харж сонгогдсон.** Test үед оргилсон 15 вирал сэдэв (в) нь яг тэр үедээ үсэрсэн учраас жагсаалтад
  орсон (ADR 0005). Иймд үр дүнг бүлгээр гаргана, гол нь (а).
- `data/aliases.csv` нь одоогийн мэдлэг (нэр солигдсныг хожим мэдсэн байж болно). Wikimedia өгөгдлөө ховор засварладаг.

## Хэрэгжүүлэлт (#50, 2026-11-25)

- `src/backtest.py`: `replay(raw, model, D)` = `truncate(raw, D)` → `serve.Snapshot.from_raw` → `serve.predict` (сервертэй
  ижил код). `python -m src.backtest run` хилээс `data/processed`-ийн сүүлийн өдөр хүртэл (~4 сек/өдөр, ~15 минут).
  Өдөр бүрийн дараа хадгалдаг тул тасарвал дахин ажиллуулахад тооцсон өдрөө алгасна.
- **Хил тохиргоонд:** `src/backtest.py`-ийн `FROM = 2026-04-01` нь `FROM_MODEL_HASH`-тай хамт. Ачаалсан model-ийн hash өөр бол
  (дахин сургасан, эсвэл `calibrate.py` `meta.json`-ийг дахин бичсэн) backtest `BoundaryOutdated`-аар зогсоно: хилийг
  шинэ хувилбарын сургалт/сонголт/калибровкт ашигласан сүүлийн өдрийн дараагийн өдөр болгож, hash-ийг шинэчлэх хүртэл.
- Гаралт `data/backtest/<model хувилбар>/`: `backtest.parquet` (asof × сэдэв: h1–h3 Δ̂/pct/80% интервал/уншилт, бодит
  Δ/pct/уншилт, бүлэг, `was_missing`, мөр бүрт `model_hash`; #51-ээс z, Anomaly, мөчлөг, нөхцөл байдлын код, "үргэлжлэх/унтрах"
  дүгнэлт: track record нь эдгээрээс, ADR 0020. Код/дүгнэлтгүй хуучин кэшийг дахин тооцно) ба `summary.json` (бүлгээр MAE/skill/хамралт, гол нь (а),
  үлдэх хазайлт). Файл доторх `model_hash` өөр бол ажиллахгүй (холихгүй). `backtest.parquet` (~15 MB, ажиллагаа бүрд дахин
  бичигдэнэ) git-д ороогүй, дахин үүсгэнэ; `summary.json` git-д.
- Анхны үр дүн (v82e4bf3, 2026-04-01 … 2026-11-10, 224 өдөр): (а) skill h1/h2/h3 +13.4/+18.6/+20.4%, 80% интервалын
  хамралт 79.5%; (в) +9.9/+13.4/+15.0%, хамралт ~71%. Test-ийн нэг удаагийн тоотой ойролцоо (суурь өөр, дээрх).
- **Бодит утга:** D+h өдрийн y нь одоогийн бүтэн өгөгдлөөр цэвэрлэсэн хүснэгтээс (бот-ын өсөлтийг хязгаарласан), суурь нь
  тэр өдөр харагдах байсан as-of y_0 (таамаг харагдсан x_0-оос хэлдэг). evaluate.py-ийн test-д y_0 нь мөн бүтэн өгөгдлөөр
  цэвэрлэсэн тул тэр нэг удаагийн тоотой шууд жишихгүй (`summary.json`-ийн `caveats`). Таамаг кэшлэгдэнэ, бодит утга
  ажиллагаа бүрд дахин тооцогдоно (сүүлийн 3 өдрийнх нь өгөгдөл нэмэгдэхэд бөглөгдөнө, сүүлийн ~14 өдрийнх түр зуурынх).
- Тест (`tests/test_backtest.py`): D-ээс хойшхи түүхий мөрийг өөрчлөхөд D-ийн replay өөрчлөгдөхгүй (бүтэн түүхээр
  цэвэрлэвэл өөрчлөгддөг тохиолдол дээр); сүүлийн asof нь `app/main.py`-ийн таамагтай бүтэн нарийвчлалаар ба
  `/api/trending`-ийн хэлбэрээр таарна; хил model хувилбартай.
