# 🔥-г сумны жингээр орлуулна. Visual channel-ийн газрын зураг: нэг channel = нэг утга

(UI/UX grill, Майк сонгосон, Claude санал болгосон, 2026-11-17.) ADR 0004-ийн 🔥 **тэмдгийг** орлоно (босго T ба тооцоо хэвээр).
🔥 нь ADR 0021/0022-ийн төвийг сахисан өнгө аястай зөрчилддөг (нас баралт, гамшгийн сэдэвт "🔥" гарна).

## Channel-ийн газрын зураг

| Channel | Утга | Жишээ |
|---|---|---|
| **Хэлбэр** (сум / ●) | чиглэл ба цаг: сум = ирээдүй (таамаг), ● = өнгөрсөн (Anomaly, ADR 0024) | ↗ ≈ ↘, ● |
| **Жин** (700 / 400, `--text-2`) | хүч ба ховор байдал: тод = model-ийн хэлж буй ховор, хүчтэй зүйл | `↗ +40%` тод, `↗ +15%` энгийн |
| **Band** (80% интервал) | итгэл | таамгийн хэсгийн band |
| **Хэв маяг** (тасархай / судал) | ажиглагдаагүй утга (таамаг), хадгалсан эсэхээс үл хамааран | таамгийн багана / шугам |
| **Шошго** (текст) | эх сурвалж (provenance): хадгалсан / сэргээж тооцсон | `сэргээж тооцсон · model v3` |

Нэг channel нэг л утгатай. **Итгэлийг жингээр харуулахгүй.** Хүчийг хэлбэрээр харуулахгүй.

## Хамгаалалт

1. Хүчийг зөвхөн жингээр биш, **тоогоор** ч давхар харуулна. Жижиг дэлгэц ба hover-гүй орчинд анхны харагдах байдлаараа уншигдана (ADR 0025).
2. "Энгийн / бүдэг" нь хоёрдогч текстийн өнгө (`--text-2`, AA 4.5:1-ээс дээш). Бага contrast-тай саарал биш.

## Prototype-д хоёр хувилбар (Майк сонгоно)

Сул таамагт урт үг ("өсөх чиглэлтэй +15%") нэмбэл хүчтэйгээс урт болж, илүү анхаарал татна. Энэ нь "тод = чухал"-ын эсрэг. Тиймээс:
- үггүй: `↗ +40%` тод / `↗ +15%` энгийн
- хүчтэйд л богино үг: `↗ +40% · хүчтэй` / `↗ +15%` энгийн

## Бууралт: тод түвшин байхгүй (Майк сонгосон)

- `↓`-г `↘`-д нэгтгэнэ (хүчийг хэлбэрээр харуулахгүй). Бүх `↘` энгийн жинтэй, хэмжээг тоо хэлнэ.
- Шалтгаан: "тод = **ховор**, хүчтэй". Таамагласан pct ≤ −20% нь өдөрт ~23 (~10%), хүчтэй өсөлт ~3.8 (~1.6%) ((в)-гүй valid, `meta.json`).
  Бууралтын ихэнх нь anomaly-ийн дараах хүлээгдэж буй "унтрах" (ADR 0021). Мөн нас баралт, гамшгийн дараах уналтыг тодруулах нь ADR 0022-ийн өнгө аясыг эвдэнэ.
- Сайтын тод зүйл хоёрхон: **хүчтэй өсөлтийн таамаг** (өдөрт ~3.8) ба **"үргэлжлэх"** дүгнэлт (өдөрт ~3.8, anomaly-ийн ~19%, ADR 0021).
  Хоёр жагсаалт давхцаж болох тул өдөрт нийт ≤ ~8 тод зүйл гарна.
- Огцом бууралт тодрохгүй ч алга болохгүй: "Бүх сэдэв"-д бууралтаар эрэмбэлэх боломжийг мэдээллийн шатлалын асуултаар шийднэ.

## Тасархай / судал = зөвхөн таамаг (UI дүрэм 4, Майк сонгосон)

- Хадгалсан ба сэргээж тооцсон таамгийг шугамын хэлбэрээр биш, **шошгоор** ялгана (ADR 0015). Хадгалсан эсэх нь өгөгдлийн утга биш, эх сурвалж.
  Тухайн view-д сэргээж тооцсон таамаг нэг ч байвал шошго **графикийн гарчгийн хажууд** үргэлж харагдана, tooltip-д нуугдахгүй.
  Tooltip-д "тухайн өдөр хэрэглэгчид харагдаагүй" гэж нэмнэ. Opacity-оор ялгахгүй (бага итгэл гэж уншигдана, band = итгэл).
- Тасархай өөр утгаар хэрэглэгдэхгүй: "Ердийн өдөр"-ийн шугам (`.norm`) нимгэн тасралтгүй бүдэг шугам болно.
  Түүх ба таамгийн зааг (`.split`) мөн тасархайгаа алдана. **Prototype-д хоёр хувилбар:** нимгэн тасралтгүй босоо шугам / таамгийн хэсгийн дэвсгэр бага зэрэг өөр.
