# 🔥-г сумны жингээр орлуулна. Visual channel-ийн газрын зураг: нэг channel = нэг утга

> Channel-ийн нэр "Хэв маяг"-ийг "**Дүүргэлт**" болгосон: "Хэв маяг" нь ADR 0022-ийн цэсний хуудасны нэр.

(UI/UX grill, Майк сонгосон, Claude санал болгосон, 2026-11-17.) ADR 0004-ийн 🔥 **тэмдгийг** орлоно (босго T ба тооцоо хэвээр).
🔥 нь ADR 0021/0022-ийн төвийг сахисан өнгө аястай зөрчилддөг (нас баралт, гамшгийн сэдэвт "🔥" гарна).

## Channel-ийн газрын зураг

| Channel | Утга | Жишээ |
|---|---|---|
| **Хэлбэр** (сум / ●) | чиглэл ба цаг: сум = ирээдүй (таамаг), ● = өнгөрсөн (Anomaly, ADR 0024) | ↗ ≈ ↘, ● |
| **Жин** (700 / 400, `--text-2`) | **ховор, анхаарах дохио** (хүчийг тоо хэлнэ). Тод тоо = pct ≥ T ба мөчлөгийн өсөлт биш; тод үг = ховор дүгнэлт ("үргэлжлэх") | `↗ +40%` тод, `↗ +15%` энгийн, **үргэлжлэх** ↗ +12% |
| **Band** (80% интервал) | итгэл | таамгийн хэсгийн band |
| **Дүүргэлт** (тасархай / судал / outline) | ажиглагдаагүй утга (таамаг), хадгалсан эсэхээс үл хамааран | таамгийн багана / шугам |
| **Шошго** (текст) | эх сурвалж (provenance): хадгалсан / сэргээж тооцсон | `сэргээж тооцсон · model v3` |

Нэг channel нэг л утгатай. **Итгэлийг жингээр харуулахгүй.** Хүчийг хэлбэрээр харуулахгүй.

## Хамгаалалт

1. Хүчийг зөвхөн жингээр биш, **тоогоор** ч давхар харуулна. Жижиг дэлгэц ба hover-гүй орчинд анхны харагдах байдлаараа уншигдана (ADR 0025).
2. "Энгийн / бүдэг" нь хоёрдогч текстийн өнгө (`--text-2`, AA 4.5:1-ээс дээш). Бага contrast-тай саарал биш.

## Prototype-д хоёр хувилбар (Майк сонгоно)

Сул таамагт урт үг ("өсөх чиглэлтэй +15%") нэмбэл хүчтэйгээс урт болж, илүү анхаарал татна. Энэ нь "тод = чухал"-ын эсрэг. Тиймээс:
- үггүй: `↗ +40%` тод / `↗ +15%` энгийн
- хүчтэйд л богино үг: `↗ +40% · хүчтэй` / `↗ +15%` энгийн

## Бууралт: тод түвшин байхгүй (Майк сонгосон)

- `↓`-г `↘`-д нэгтгэнэ (хүчийг хэлбэрээр харуулахгүй). Бүх `↘` энгийн жинтэй, хэмжээг тоо хэлнэ.
- Шалтгаан: "тод = **ховор**, хүчтэй". Таамагласан pct ≤ −20% нь өдөрт ~23 (~10%), хүчтэй өсөлт ~3.8 (~1.6%) ((в)-гүй valid, `meta.json`).
  Бууралтын ихэнх нь anomaly-ийн дараах хүлээгдэж буй "унтрах" (ADR 0021). Мөн нас баралт, гамшгийн дараах уналтыг тодруулах нь ADR 0022-ийн өнгө аясыг эвдэнэ.
- Сайтын тод зүйл хоёрхон: **хүчтэй өсөлтийн таамаг** (өдөрт ~3.8 ⚠️ **хуучирсан**: мөчлөгийн өсөлтийг хасахаас өмнөх тоо, доорх хэсгийг үз; давтамжийн скриптээр шинэчилнэ) ба **"үргэлжлэх"** дүгнэлт (өдөрт ~3.8, anomaly-ийн ~19%, ADR 0021).
  Хоёр жагсаалт давхцаж болох тул өдөрт нийт ≤ ~8 тод зүйл гарна.
- Огцом бууралт тодрохгүй ч алга болохгүй: "Бүх сэдэв"-д бууралтаар эрэмбэлэх боломжийг мэдээллийн шатлалын асуултаар шийднэ.

## Тасархай / судал = зөвхөн таамаг (UI дүрэм 4, Майк сонгосон)

- Хадгалсан ба сэргээж тооцсон таамгийг шугамын хэлбэрээр биш, **шошгоор** ялгана (ADR 0015). Хадгалсан эсэх нь өгөгдлийн утга биш, эх сурвалж.
  Тухайн view-д сэргээж тооцсон таамаг нэг ч байвал шошго **графикийн гарчгийн хажууд** үргэлж харагдана, tooltip-д нуугдахгүй.
  Tooltip-д "тухайн өдөр хэрэглэгчид харагдаагүй" гэж нэмнэ. Opacity-оор ялгахгүй (бага итгэл гэж уншигдана, band = итгэл).
- Тасархай өөр утгаар хэрэглэгдэхгүй: "Ердийн өдөр"-ийн шугам (`.norm`) нимгэн тасралтгүй бүдэг шугам болно.
  Түүх ба таамгийн зааг (`.split`) мөн тасархайгаа алдана. **Prototype-д хоёр хувилбар:** нимгэн тасралтгүй босоо шугам / таамгийн хэсгийн дэвсгэр бага зэрэг өөр.

## Таамгийн өнгө: нэг сэдэв = нэг hue (UI дүрэм 2, Майк сонгосон)

- Таамаг нь бодит уншилтын **ижил hue**-тэй, **дэвсгэр рүү ойртсон tint** + дүүргэлт (судал / тасархай) + band. Таамгийн тусдаа hue байхгүй.
  ("Цайвар" биш: бараан theme дээр цайвар өнгө бодит баганаас тод харагдана.)
- Дүрэм: таамаг **аль ч theme дээр бодит өгөгдлөөс бага анхаарал татна**, гэхдээ дэвсгэртэйгээ **≥ 3:1** contrast-тай (WCAG 1.4.11). Prototype шатанд `dataviz` validator-аар шалгана.
- Шалтгаан: таамаг бол ижил хэмжигдэхүүний үргэлжлэл. Өөр hue нь "өөр хувьсагч" гэж уншигдана. Цөөн hue нь CVD-ийн эрсдэлийг бууруулна.

## Replay: өнгөрсөн таамаг нь дүүргэлтгүй mark

Replay-д бодит үр дүн ба тэр өдрийн таамаг ижил өдрүүд дээр зэрэг гарна. Ижил hue-тэй хоёр багана бие биенээ дарна.
- Бодит = дүүргэсэн багана. Тэр өдрийн таамаг = **дүүргэлтгүй mark** (outline эсвэл хэвтээ tick) + band.
- Channel-ийн газрын зурагт **шинэ мөр нэмэхгүй**. Дүүргэлтгүй mark нь "дүүргэлт = ажиглагдаагүй утга" мөрийн нэг хэлбэр.
  Өнгөрсөн ба ирээдүйн таамгийг цагийн тэнхлэг дээрх **байрлал** (өнөөдрийн заагийн өмнө / хойно) аль хэдийн ялгадаг.
- **Цэгтэй шугам хэрэглэхгүй:** ● = Anomaly (ADR 0024), цэг нь "энэ өдөр огцом өссөн" гэж уншигдана.
- **Prototype-д хоёр хувилбар:** outline багана / хэвтээ tick (хоёулаа band-тай).

## Мөчлөгийн өсөлт хэзээ ч тод биш (UI дүрэм 6, Майк сонгосон)

- **Тод = таамагласан pct ≥ T ба мөчлөгийн өсөлт биш** (ADR 0019). T ба түүний тааруулга (ADR 0004) хэвээр.
  Жишээ: мөчлөг +30%, таамаг +40% → илүүдэл ≈ +8% → мөчлөгийн өсөлт → `↗ +40%` **энгийн** жинтэй.
- Татгалзсан: тодыг илүүдэл e ≥ T-ээр тодорхойлох. Шинэ босго, тоо шаардах ба тод нь харагдах тоо (түүхий pct)-оос өөр сууриас гарна.
- **Урьдчилсан нөхцөл (заавал):** ижил `↗ +40%` нэг сэдэвт тод, нөгөөд энгийн байж болно. Тиймээс мөчлөгийн өсөлтийн **тайлбар заавал харагдана**,
  сонголт биш. Ингэхгүй бол жин ба тоо зөрчилдөж харагдана. Хэлбэрийг UI grill-ийн дараагийн асуултаар шийднэ.

### Мөчлөгийн тайлбарын хэлбэр (Майк сонгосон)

- **Үг заавал хаа сайгүй:** `↗ +40% · долоо хоног бүр ийм` (энгийн жин). Tooltip: "энэ гарагуудад ердийн долоо хоногт +30% өсдөг".
  Prototype-д хоёр хувилбар: "долоо хоног бүр ийм" / "долоо хоногийн хэвийн өсөлт", **~375px өргөнтэй картанд нэг мөрөнд багтах эсэхийг** шалгана.
- **Графикийн тэмдэг нь зөвхөн prototype-ийн хувилбар.** График нь уншилт, мөчлөг нь анхаарал дээр (ADR 0014, 0019), мөн мөчлөг зөвхөн h3-т тодорхойлогдсон.
  Гарвал зөвхөн h3 өдөр, нимгэн тасралтгүй (тасархай = таамаг). Хоёр хувилбар: хэвтээ tick / h3 өдөр дээрх жижиг шошго.
- **Хэвтээ tick нэг л утгатай.** Replay-ийн өнгөрсөн таамаг tick сонгогдвол мөчлөгийн тэмдэг шошго болно, эсрэгээрээ ч мөн адил.

## Жин = "ховор дохио", тоо ба үг тусдаа дүрэмтэй (Майк сонгосон)

Өмнө жин нь "хүч ба ховор байдал" гэсэн хоёр утгатай байсан. "Үргэлжлэх" картын `↗ +12%`-г тод болговол Давж өсөх жагсаалтын энгийн `↗ +20%`-тай зөрчилдөнө.
- **Тод тоо** сайтын хаана ч нэг утгатай: pct ≥ T ба мөчлөгийн өсөлт биш.
- **"Үргэлжлэх"** дүгнэлтэд **үг** тодорно, тоо нь тооны дүрмээр: `**үргэлжлэх** ↗ +12%`, `унтрах ↘ −35%`.
- Тод үг ба тод тоо нэг картанд давхцаж болно ("**үргэлжлэх** ↗ **+40%**"). Энэ нь хоёр ховор дохио давхцсан тул зөв. Хэт хүнд харагдах эсэхийг prototype-д шалгана.
