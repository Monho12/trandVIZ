# Model сайтын ард ажиллана; Hugging Face Spaces дээр байршуулна

ADR 0006-ийг орлоно. ADR 0006-д "зөвхөн урьдчилан тооцоолсон JSON" гэж шийдсэн байсан ч энэ нь Майкийн шаардлагыг хангахгүй,
учир нь model сайтын ард ажиллахгүй байсан.

**Майкийн шаардлага (үгчлэн):** "the model must be deployed behind the website."
**Байршуулах газар:** Hugging Face Spaces (Docker + FastAPI). Энэ бол Майкийн шийдвэр. (2026-11-09)

## Загвар

- FastAPI эхлэхдээ сургасан model-ийн файлуудыг (`app/model/`: 3 horizon + `meta.json`) **ачаална**.
- Хүсэлт бүрт (сэдэв эсвэл ангилал сонгоход) backend **inference ажиллуулна**.
- Wikipedia өгөгдлийг **өдөрт нэг удаа** татаж, сервер дээр cache хийнэ. API унавал **сүүлийн cache**-ийг ашиглана.
- `/api/model` нь ямар алгоритм ачаалагдсаныг (`meta.json`-ийн `algo`, сургасан огноо, өгөгдлийн asof) харуулна.
  Ингэснээр хамгаалалтын үеэр model амьд ажиллаж байгааг харуулж болно.
- Сургалт болон сервер **ижил** цэвэрлэгээ (alias, үсрэлт хязгаарлах, causal trim) болон `src/features.py`-г ашиглана. Үгүй бол train/serve зөрүү үүснэ.

## Хэвээр үлдэх дүрэм (ADR 0006-аас)

- User-Agent нь `Shuugian/1.0 (https://github.com/Monho12/trandVIZ)`, и-мэйл оруулахгүй. Wikimedia тайлбартай UA шаарддаг, үгүй бол 403 өгнө.
- D өдрийн өгөгдөл хараахан гараагүй эсвэл `total_views` дутуу бол ~3 цагийн дараа **нэг удаа** дахин оролдоно. Тэгээд ч болохгүй бол сүүлийн cache-ийг ашиглана.
- Вэбэд тодорхой огноо ("11/11–11/13") болон өгөгдлийн asof-ийг бичнэ. asof нь 2-оос олон өдрийн өмнөх бол шар анхааруулга гарна.
- `level_365` 365 хоногийн түүх шаарддаг тул сервер ≥ 400 хоногийн түүхтэй байх ёстой.

## Лхагвын дараалал (эхлээд аюулгүй байдал)

1. Docker image-ийг бүтээж **local дээр** ажиллуулж шалгана.
2. Дараа нь Space руу deploy хийнэ.
3. Онлайнаар ажиллаж байгааг шалгана.

Пүрэв гарагт үнэгүй Space унтдаг тул хамгаалалтаас 5 минутын өмнө нээж сэрээнэ.

HF account болон access token-ийг **Майк өөрөө** үүсгэнэ. Token-ийг **хэзээ ч repo-д оруулахгүй**.
