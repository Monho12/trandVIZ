# "Идэвхгүй өдөр"-ийг хасахдаа зөвхөн өнгөрсөн өгөгдөл ашиглана

`src/clean.py`-ийн `trim_inactive` нь сэдвийн **сүүлийн** 365 хоногийн медианыг (ирээдүй) ашиглаад, 7 хоногийн дундаж уншилт нь
тэр медианы 2%-д хүрэхээс өмнөх өдрүүдийг хасдаг. Гэтэл "алдартай болохоос өмнөх нам гүм үе" бол яг бидний таамаглах гэж буй
вирал болохын өмнөх үе. Энэ нь look-ahead юм: ажиллуулах огноогоос үр дүн нь хамаарна (`trim_report.csv`-д 11,089 хоног,
одоогийн өгөгдлөөр дахин тооцоход 7,047 хоног гарсан). (Майк, 2026-11-09)

Хасагдсан өдрүүдийн байршил (одоогийн өгөгдлөөр):

| бүлэг | train | valid | test |
|---|---|---|---|
| (а) сонгосон | 2,287 | 0 | 0 |
| (б) хуучин вирал | 890 | 0 | 0 |
| (в) шинэ вирал | 3,772 | **98** | 0 |

Valid-д 98 хоног хасагдсан (Lokah 70, Untamed (TV series) 28), бүгд (в) бүлгийнх. (в) нь сонголт болон T тааруулалтаас аль хэдийн
хасагдсан бөгөөд test-д нөлөө 0. Гэсэн ч > 0 тул засна.

**Шийдвэр (Мягмарын эхний алхам):** trim-ийг **causal** болгоно. "Идэвхтэй" гэдгийг t өдөр хүртэлх (trailing) 365 хоногийн медианаар
тодорхойлж, `ACTIVE_ABS = 100` хэвээр үлдээнэ. Үүний дараа clean, features, baselines-ийг дахин үүсгэж, `pytest` болон baseline-ийн тоог шалгана.
Trim нь t+1-ээс хойшхи өгөгдлийг ашиглахгүй гэдгийг батлах тест нэмнэ. **Цаг хүрэхгүй бол** хуучин trim-ийг сургалтад үлдээж,
хасагдсан valid/test мөрүүдийг **үнэлгээнд буцааж оруулна**.
