# Trend-ийг регрессээс босгоор гаргаж, хоёр босгыг ялгана

Загвар нь регресс хэвээр байна: target нь `y_h − y_0` (y = log1p(анхаарал)), loss нь L1, алгоритмыг validation MAE-гаар сонгоно.
"Trend" гэдэг бол тусдаа загвар биш, энэ таамгаас дүрмээр гаргадаг шошго. Нүүрэнд таамагласан 3 өдрийн
өсөлтөөр эрэмбэлсэн top-10 гарна. Ангилал хийх загварыг сонгоогүй, учир нь target, хэмжүүр, 04_model бүгд
өөрчлөгдөх байсан. (Майк, 2026-11-09; ADR 0003-аар хувь руу шилжүүлсэн)

## Хоёр босго (ялгаатай)

Хоёулаа **хувиар** (ADR 0003) тооцогдоно: pct = x_h / x_0 − 1, энд x нь анхаарал.

- **Үнэн trend (үнэлгээний шошго)** нь **бодит** утгаар тодорхойлогдоно: h3 дээр pct ≥ +25% бол "↑ өсөж байна",
  pct ≤ −20% бол "↓ унаж байна", бусад нь "тогтвортой".
- **🔥 шошго (вэб)** нь **таамаг** дээр тогтоосон нэг тогтмол босго. Үүнийг valid дээр өдөрт ~5–10 сэдэв
  гарахаар тааруулна. Шалтгаан нь L1 загвар медианыг таамагладаг тул таамаг 0 руу ойртож, +25%-иас дээш таамаг
  ховор гардаг. Эхлээд valid дээрх таамгийн тархалтыг (квантилиуд, өдөр бүр хэдэн сэдэв босго давах) харж байж
  тогтооно.

## Нэмэлт хэмжүүр (зөвхөн үнэлгээ, target болон загвар өөрчлөгдөхгүй)

- **MAE**: лог хуваарьт, horizon бүрээр, naive ба seasonal-тай харьцуулна. Алгоритм сонгох ганц шалгуур хэвээр.
- **precision@10 (h3)**: өдөр бүр таамагласан pct-ээр top-10 сэдвийг аваад, тэдгээрийн хэдэн хувь нь үнэн trend (↑)
  байсныг тооцож, өдрүүдийн дунджийг авна.
- **Чиглэлийн нарийвчлал**: ADR 0002-ыг үз.
- Momentum baseline-ийг ADR 0002-т тогтоосон.
