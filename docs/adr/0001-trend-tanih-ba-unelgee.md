# Trend-ийг регрессээс босгоор гаргаж, хоёр босгыг ялгана

Загвар нь регресс хэвээр байна: target нь `y_h − y_0` (лог анхаарал), алгоритмыг validation MAE-гаар сонгоно.
"Trend" гэдэг бол тусдаа загвар биш, энэ таамгаас дүрмээр гаргадаг шошго. Нүүрэнд таамагласан 3 өдрийн
өсөлтөөр эрэмбэлсэн top-10 гарна. Ангилал хийх загварыг (B) сонгоогүй, учир нь target, хэмжүүр, 04_model бүгд
өөрчлөгдөх байсан. (Майк, 2026-11-09)

## Хоёр босго (ялгаатай)

- **Үнэн trend (үнэлгээний шошго)** нь **бодит** утгаар тодорхойлогдоно: h3 дээр Δ ≥ log(1.25) ≈ 0.223 бол "↑ өсөж байна",
  Δ ≤ log(0.8) ≈ −0.223 бол "↓ унаж байна", бусад нь "тогтвортой".
- **🔥 шошго (вэб)** нь **таамаг** дээр тогтоосон нэг тогтмол босго. Үүнийг valid дээр өдөрт ~5–10 сэдэв
  гарахаар тааруулна. Шалтгаан нь L1 (MAE) загвар медианыг таамагладаг тул таамаг 0 руу ойртож, +0.22-оос дээш таамаг
  ховор гардаг. Эхлээд valid дээрх таамгийн тархалтыг (квантилиуд, өдөр бүр хэдэн сэдэв босго давах) харж байж
  тогтооно. "↓" шошгыг мөн адил, тэгш хэмтэйгээр тааруулна.

Шошгыг бодит Δ-ээр, харин 🔥-г таамгаар тодорхойлдог нь санаатай: 🔥-ийн босгыг "үнэн trend"-ийн босготой
адилтгаж болохгүй.

## Нэмэлт хэмжүүр (зөвхөн үнэлгээ, target болон загвар өөрчлөгдөхгүй)

- **MAE**: horizon бүрт, naive ба seasonal-тай харьцуулна. Алгоритм сонгох ганц шалгуур хэвээр.
- **precision@10 (h3)**: өдөр бүр таамгаар top-10 сэдвийг аваад, тэдгээрийн хэдэн хувь нь үнэн trend (↑) байсныг
  тооцож, өдрүүдийн дунджийг авна.
- **Чиглэлийн нарийвчлал**: таамгийн тэмдэг бодит Δ-ийн тэмдэгтэй таарсан хувь.
- **Чиглэлийн baseline = momentum** ("сүүлийн 3 өдрийн чиг үргэлжилнэ"): Δ̂ = y_0 − lag_3 (`growth_3`).
  precision@10-ийн эрэмбэлэлтэд мөн энэ baseline-ийг ашиглана. Naive бүх сэдэвт 0 өгдөг тул эрэмбэлж чадахгүй.
