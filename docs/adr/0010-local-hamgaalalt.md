# Сайтыг хамгаалалт дээр local-оор ажиллуулна; Hugging Face Spaces-ээс татгалзсан

> **2026-11-10:** онлайн линкийг ADR 0011 нэмсэн (Render.com free, серверт зөвхөн CatBoost). Local нь нөөц болж хэвээр.

(Майкийн шийдвэр, 2026-11-10.) ADR 0008-ийн **байршуулах газар** хэсгийг орлоно. Model сайтын ард ажиллах загвар
(эхлэхдээ model ачаалах, хүсэлт бүрт inference, өдөр тутмын cache, `/api/model`) хэвээр.

## Яагаад

Hugging Face 2026 оны 7-р сараас шинэ **Docker** болон **CPU Basic** Space үүсгэхэд PRO төлбөр шаарддаг болсон
(https://huggingface.co/docs/hub/en/spaces-overview). Үнэгүй эрхээр зөвхөн Gradio + ZeroGPU эсвэл Static Space үүсгэнэ.
Static нь backend-гүй тул "the model must be deployed behind the website" шаардлагыг хангахгүй. Gradio + ZeroGPU дээр
FastAPI сервер болон арын шинэчлэлтийн thread ажиллах эсэх нь баталгаагүй, хамгаалалт 2 хоногийн дараа.

Харьцуулсан сонголтууд: HF PRO (~$9/сар, кодын өөрчлөлтгүй), үнэгүй Gradio + ZeroGPU (тааруулах шаардлагатай, эрсдэлтэй),
зөвхөн local. Майк **зөвхөн local**-ийг сонгосон.

## Загвар

- Хамгаалалт дээр Майкийн компьютер дээр `uvicorn app.main:app` (http://127.0.0.1:8000) ажиллана.
  Docker байгаа бол `docker run -p 7860:7860 shuugian` нь ижил сайт (http://127.0.0.1:7860).
- Интернэт байвал сервер Wikimedia-аас дутуу өдрүүдийг татна. Интернэтгүй бол `SHUUGIAN_REFRESH=0`: image/repo доторх
  `data/processed/` дээр ажиллаж, asof хуучин бол шар анхааруулга гарна.
- `Dockerfile` хэвээр үлдэнэ: ижил орчинг давтах, дараа нь онлайн байршуулах бол эхлэл болно.
  HF-д зориулсан deploy скрипт ба README-ийн YAML толгойг хассан.

## Үр дагавар

- Онлайн линк байхгүй. `/api/model`-ийг local-оос нээж model амьд ажиллаж байгааг харуулна.
- Ирээдүйд онлайн байршуулах бол HF PRO эсвэл Docker дэмждэг өөр host дээр одоогийн `Dockerfile`-ийг ашиглана
  (контейнер ~420 MB санах ой хэрэглэдэг тул 512 MB-ийн үнэгүй багцад хэт давчуу).
