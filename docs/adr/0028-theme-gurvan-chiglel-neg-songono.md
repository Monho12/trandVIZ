# Theme: prototype-д 3 чиглэл, Майк нэгийг сонгоно, light/dark сэлгэгчгүй. ● = текстийн өнгө

(UI/UX grill, Майк сонгосон, Claude санал болгосон, 2026-11-17.) ADR 0023-ын "бараан theme нь хувилбаруудын нэг л" гэдгийг хэрэгжүүлнэ.

## Бүх чиглэлд нийтлэг

- Брэнд (улаан / цэнхэр / цагаан) нь зөвхөн лого, гарчиг, accent-д (ADR 0023).
- Өгөгдөл **нэг hue**: бодит = тод, таамаг = дэвсгэр рүү ойртсон tint, band (ADR 0026). Таамаг нь бодитоос бага анхаарал татах ч дэвсгэртэйгээ ≥ 3:1.
- Текст AA ≥ 4.5:1. CVD ба contrast-ыг `dataviz` validator-аар шалгана.
- **● = текстийн өнгө (бэх)**, hue биш. Шугамын hue-тэй ижил бол алга болно, өөр hue (шар хүрэн г.м.) бол "анхааруулга" гэж уншигдана.
- **Treemap:** нүдний өнгө = өгөгдлийн hue-ийн sequential scale (×N их = тод), Anomaly нүдэнд ● тавина (ADR 0024). Брэндийн улаанаас шилжинэ.

## Гурван чиглэл

| | 1. Цайвар, одоогийнхтой ойр | 2. Цайвар "цаас" | 3. Бараан, нам гүм |
|---|---|---|---|
| Дэвсгэр | `#f4f5f7` / цагаан карт | дулаан цагаан, цаас мэт | гүн саарал-цэнхэр (хар биш) |
| Өгөгдлийн hue | брэндийн цэнхэртэй ойр, тусдаа token | бэх шиг бараан саарал-цэнхэр (бараг монохром) | бүдэг ган-цэнхэр (neon биш) |
| Эрсдэл | брэнд ба өгөгдөл хоёулаа цэнхэр | хэт "хуучин сонин", interactive мэдрэмж сул | tint ба band-ийн contrast хамгийн хэцүү |

## Нэг theme, сэлгэгчгүй

Хоёр theme-ийг AA, CVD, band-ийн contrast-аар зэрэг хадгалах нь шалгалтын ачааллыг хоёр дахин нэмнэ. Тиймээс `prefers-color-scheme`-ийг дагахгүй,
сонгосон нэг theme бүх хэрэглэгчид.

## Prototype-ийн шалгуур

- **Treemap дээрх ●:** ×N их нүд хамгийн тод / бараан тул бэх өнгийн ● харагдахгүй болно. Хоёр хувилбар: дэвсгэрийн өнгийн halo / хүрээтэй, эсвэл бараан нүдэн дээр урвуу өнгө.
  Гурван theme бүрт хамгийн бараан нүдэн дээрх ●-ийн contrast ≥ 3:1.
- **Үнэлгээ хоёр тэнхлэгтэй:** "ойлгомжтой" (5 секунд, contrast) **ба** "өвөрмөц" (ADR 0025). Өнгө нь бүгд нам гүм тул өвөрмөц мэдрэмж typography, motion,
  interaction-оос гарна. Чиглэл бүрт font-ын хослол ба нэг motion-ий жишээ (жишээ нь холбоотой hover-ийн тодрол) харуулна. `impeccable`, `emil-design-eng` ашиглана (ADR 0025).
