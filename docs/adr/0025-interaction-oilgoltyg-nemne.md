# Interaction нь ойлголтыг нэмнэ, чимэглэл биш. UI ажлын skill-ийг Майк тогтоосон

(UI/UX grill, Майкийн шаардлага, 2026-11-17.)

## Шаардлага

UI нь interactive, өвөрмөц байна. Гэхдээ **ойлгомжтой байдал нэгдүгээрт**. Шинэ хэрэглэгч ямар ч interaction хийлгүйгээр
5 секундэд "энэ сэдэв өсөх үү, буурах уу, хэр итгэлтэй вэ?" гэдгийг ойлгох ёстой. Interaction нь тэр ойлголтыг гүнзгийрүүлнэ, орлохгүй.

- Interaction-д өгөгдөл ба тайлбарын үүрэг байх ёстой. Зөвхөн "гоё" харагдуулах interaction хийхгүй.
- Motion богино, утгатай. `prefers-reduced-motion`-ийг хүндэтгэнэ.
- Interaction бүр гар утсан дээр (hover байхгүй) tap-аар ажиллана.
- ADR 0023 хүчинтэй: Майк prototype-оос сонгохоос өмнө юу ч кодод орохгүй.

## Prototype дээр харах interaction-ууд (санал, батлагдаагүй)

1. **Холбоотой hover:** жагсаалтын ● ↔ сэдвийн график дээрх тухайн өдрийн багана (ADR 0024).
2. **Итгэлийн band:** таамгийн хэсэгт "80% магадлалтай энэ хооронд" гэж энгийн үгээр гарна.
3. **Replay "өнгөрсөн таамаг хэр зөв байсан бэ":** өнгөрсөн нэг өдрийн таамаг ба бодит үр дүн давхцаж харагдана.
4. **"Яагаад?" дэлгэгддэг тайлбар:** 1–2 өгүүлбэр, дарахад л гарна.
