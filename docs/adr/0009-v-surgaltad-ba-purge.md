# (в) бүлгийг сургалтад оруулна; хуваалтын хил дээр 3 хоногийн purge хийнэ

(Майк зөвшөөрсөн (Claude санал болгосон), 2026-11-10)

## (в) нь сургалтад орно

(в) бүлэг (valid/test үед оргилсон 36 вирал сэдэв)-ийн train хугацааны мөрүүд нь оргилоос **өмнөх** нам гүм үе юм.
Тэдгээрт ирээдүйн мэдээлэл байхгүй, `category` хасагдсан тул "вирал" гэсэн дохио ч байхгүй (ADR 0005). Хасвал загвар
нам гүм сэдвүүдээс бага суралцана. Сонголтын хазайлт нь зөвхөн **үнэлгээнд** нөлөөлдөг бөгөөд үүнийг аль хэдийн
шийдсэн: алгоритм сонгох, T тааруулах, интервалын residual тооцоход (в)-г хасдаг, үр дүнг бүлгээр тайлагнадаг.

## Хуваалтын хил дээрх purge

Мөр бүр t өдрөөрөө хуваалтад ордог, харин target нь t+1…t+3 өдрийнх. Purge хийхгүй бол 2025-06-28…30-ны train мөрийн
target нь valid-ийн өдөр болно. Жишээ нь 2025-07-д оргилсон (в) сэдвийн үсрэлтийн эхлэл train руу нэвчинэ. Valid → test хил
дээр мөн адил. Иймд **t + max(h) нь мөрийнхөө хуваалтаас гарч байвал тэр мөрийг хасна**
(`src/features.py: purge_split_boundary`, тест: `test_split_boundary_purge_drops_rows_whose_target_crosses_split_end`).
Хил бүр дээр 3 өдөр × 301 сэдэв хасагдана. Test-ийн төгсгөлд хил байхгүй (target-гүй мөр аль хэдийн хасагддаг).

**Үр дүн (дахин үүсгэсний дараа):** features 578,954 мөр (train 432,722, valid 81,818 → 80,915, test 65,317 хэвээр).
Baseline-ийн valid MAE: naive h1/h2/h3 0.1119/0.1589/0.1824 → 0.1119/0.1586/0.1822,
seasonal 0.2108/0.2109/0.2109 → 0.2109/0.2107/0.2107. Test-ийн тоо **өөрчлөгдөөгүй**.
