## 04_model-ийн үнэлгээ (Майк, 2026-11-09 — ADR 0001–0004)

Загвар, target (`y_h − y_0`, y = log1p(анхаарал)), L1 loss, хуваалт **өөрчлөгдөхгүй**. Feature нь **18** ширхэг: `category`-г хассан (ADR 0005), `feature_list.json`-оос уншина. Доорх зүйлс бол зөвхөн үнэлгээ ба хувиргалт.

**Хувь руу хувиргах (ADR 0003).** x = анхаарал. Таамаг x̂_h = expm1(y_0 + Δ̂), pct = x̂_h / x_0 − 1. Бодит утга мөн адил: x_h / x_0 − 1.
L1 нь медианыг таамагладаг тул bias засвар хэрэггүй, 80% интервалыг ч мөн expm1-ээр шууд хувиргана.

**Тодорхойлолт.**
- Үнэн trend: бодит pct (h3) ≥ +25% бол ↑, ≤ −20% бол ↓, бусад нь тогтвортой.
- Хэмжигдэх сэдэв: сүүлийн 7 хоногийн дундаж анхаарал **x хуваарьт** ≥ 1 (`roll_mean_7` нь log1p хуваарьт тул түүнийг ашиглахгүй).
- Momentum baseline (тогтмол): momentum = y_0 − y_{−3}. Чиглэл = sign(momentum), top-10 = momentum-оор эрэмбэлсэн.

**Leakage, сонголтын хазайлт (ADR 0005).**
- `category`-г загварт **оруулахгүй** (feature 18). `tests/test_features.py` үүнийг шалгана. 03-ыг дахин ажиллуулбал `pytest -q` хийнэ.
- Бүлгүүдийг `viral_articles.csv`-ийн `peak_month`-аар тодорхойлно: (а) сонгосон 151, (б) хуучин вирал ≤ 2025-06 (114), (в) шинэ вирал ≥ 2025-07 (36).
- **Алгоритм сонгох valid MAE болон T-г тааруулахад (в)-г хасна.** Сургалтад бүх бүлэг орно.
- Test-ийн бүх хэмжүүрийг, загвар болон naive, momentum бүгдийг, **(а)/(б)/(в) бүлэг тус бүрт** тайлагнана. Гол дүгнэлт нь (а).
  (б)-ийн "↓" чиглэл хэт сайн харагдана (оргилын дараах уналт), (в) нь сонголтын хазайлттай. Эдгээрийг гол дүгнэлт болгохгүй.

**Тайлагнах (valid нь (в)-гүй, тэгээд test нэг удаа).** Алгоритм сонгох шалгуур нь зөвхөн valid MAE ((в)-г хассан).
1. MAE (лог, **бүх мөр**), h1/h2/h3. Харьцуулах нь naive, seasonal. Skill score = 1 − MAE/MAE_naive.
2. precision@10 (h3, хэмжигдэх сэдэв): өдөр бүрийн таамагласан pct-ээр top-10 сэдвийн хэдэн хувь нь үнэн ↑ болсон бэ, өдрүүдийн дундаж.
   Хажууд нь momentum-ийн precision@10 болон **үндсэн хувь** (тухайн өдөр хэмжигдэх сэдвүүдийн ↑-ийн эзлэх хувь).
3. Чиглэлийн нарийвчлал (хэмжигдэх сэдэв): **ӨСӨХ** (бодит pct ≥ +25%) ба **БУУРАХ** (≤ −20%) мөрүүд дээр **тусад нь**, загвар ба momentum.
4. Найдвартай байдал: test-ийн өдрүүдийн хэдэн хувьд загварын MAE < naive байсан бэ (h бүрээр).
5. 🔥 босго: valid ((в)-гүй) дээрх таамагласан pct (h3)-ийн тархалт (квантилиуд). **T = 25% үед өдөрт дунджаар хэдэн 🔥** гарах вэ.
   T = max(өдөрт ~5–10 гаргах босго, 25%). Сонгосон T-г `app/model/meta.json`-д хадгална.

**Амжилтын шалгуур (test-ээс өмнө тогтоосон, ADR 0002).**
- Skill score ≥ 5% (h1, h2, h3 бүрт).
- precision@10 > momentum.
- **Гол шалгуур:** ӨСӨХ мөрүүдийн чиглэлийн нарийвчлал > momentum.
- Шалгуур давахгүй бол нуухгүй, слайдад шалтгаантай нь харуулна.

## Вэбийн харагдах байдал (ADR 0003, 0004) — дизайн хэвээр, зөвхөн текст, тоо

- Гол тоо нь h3-ын pct, 5%-д дугуйлна. +300%-иас их бол "↑ 3×-ээс их". Хажууд нь 80% интервалыг саарлаар бичнэ. h1, h2 нь графикийн шугам дээр.
- Сум: ≥ T бол 🔥, +10%…T бол ↗ x%, ±10% бол ≈ тогтвортой, −10…−20% бол ↘ x%, ≤ −20% бол ↓ унаж байна.
- Top-10 үргэлж дүүрэн, хэмжигдэх сэдвээс бүрдэнэ. Нам гүм өдөр 🔥 огт гарахгүй байж болно.
- "Бүх сэдэв" хуудсанд жижиг сэдэв pct-ээ харуулна, гэхдээ 🔥 авахгүй.
- Вирал сэдвийн ангиллыг "Бусад" гэж харуулна (ADR 0005).
- "Уншилт" биш "анхаарал" гэж бичнэ. Tooltip: "Wikipedia-ийн нийт уншилтад эзлэх хувь".
